LOT / SCS 모델별 수량 비교

두 Excel 파일을 각각 업로드하면 모델 ID를 연결하고 LOT 기준 MES 수량과 SCS 기준 Starpro 수량을 모델별·전체로 비교합니다. 파일은 이 브라우저 안에서만 읽으며 서버로 전송하지 않습니다.

1. LOT 등록 파일

LOT 등록 페이지와 같은 형식의 Excel 파일을 선택하세요. 헤더명으로 열을 찾아 처리하므로 열 순서가 바뀌어도 됩니다.

선택된 파일 없음
필수 열: 활동, 제품ID. `INPUT_LOT` 행을 모델별로 세고 Array를 곱해 MES상 수량을 계산합니다. 원본 13열 LOT 등록 형식도 지원합니다.

2. SCS 처리 파일

SCS 처리 Excel 파일을 선택하세요. `Part No`의 모델 ID를 LOT 등록 모델 ID와 자동 연결합니다.

선택된 파일 없음
필수 열: Part No, Departure Qty, Non-Receiving Qty. Starpro 수량은 모델별로 `Departure Qty − Non-Receiving Qty`를 합산합니다.

모델별 비교 결과

Array 값은 기준표에서 확인·수정할 수 있습니다. 새 모델은 Array를 입력하면 MES상 수량에 반영됩니다.

제품명모델 IDArrayLOT INPUT_LOTMES상 수량Starpro 수량차이 (MES − Starpro)

지원 형식: Excel `.xlsx`, `.xlsm`. 수량 비교의 Array 기준은 제공된 수량 비교 파일의 모델별 설정을 사용합니다. 매칭되지 않거나 정규화 후 서로 다른 Array 기준이 충돌하는 모델은 임의 계산하지 않고 별도로 표시합니다.
