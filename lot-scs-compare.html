LOT / SCS 모델별 수량 비교

LOT와 SCS Excel 파일을 업로드하거나 표를 복사해 붙여넣으면 모델 ID를 연결하고 LOT 기준 MES 수량과 SCS 기준 Starpro 수량을 비교합니다. 데이터는 이 브라우저 안에서만 처리됩니다.

Excel 통합 문서 업로드

LOT와 SCS 시트가 함께 있는 통합 문서를 선택하면 각 표를 자동으로 찾아 비교합니다. 두 파일로 나뉘어 있으면 아래 각 영역에서 따로 업로드할 수 있습니다.

파일은 브라우저 안에서만 처리됩니다.
시트 이름은 상관없습니다. 헤더를 기준으로 LOT 및 SCS 표를 찾습니다.

1. LOT 등록 표

LOT Excel 파일을 업로드하거나, 표 전체를 복사해 아래에 붙여넣으세요.

Excel 파일을 선택하세요.
표를 붙여넣으세요.
헤더가 있는 표는 제품ID와 활동 열을 찾아 처리합니다. 헤더 없이 붙여넣는 13열 LOT 표도 지원하며, 이 형식은 3번째 열의 `INPUT_LOT`와 5번째 열의 제품ID를 읽습니다.

2. SCS 처리 표

SCS Excel 파일을 업로드하거나, 표 전체를 복사해 아래에 붙여넣으세요.

Excel 파일을 선택하세요.
표를 붙여넣으세요.
필수 열: Part No, Departure Qty, Non-Receiving Qty. 수량이 `2,269.00`처럼 텍스트로 붙여넣어져도 숫자로 읽어 `Departure Qty − Non-Receiving Qty`를 합산합니다.

모델별 비교 결과

Array 값은 기준표에서 확인·수정할 수 있습니다. 새 모델은 Array를 입력하면 MES상 수량에 반영됩니다.

제품명모델 IDArrayLOT INPUT_LOTMES상 수량Starpro 수량차이 (MES − Starpro)

붙여넣으면 자동으로 계산됩니다. 입력 내용을 직접 수정한 경우 반영 버튼을 누르세요. 헤더명으로 열을 찾으므로 열 순서는 달라도 됩니다. 수량 비교의 Array 기준은 모델별 설정을 사용하며, 붙여넣은 데이터는 서버로 전송되지 않습니다.
