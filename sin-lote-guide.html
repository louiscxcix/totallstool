PROCESO · PASO A PASO

Recuperación de SIN LOTE

Sigue los pasos en orden. Primero verifica si el LOT existe; después, corrige únicamente el caso confirmado.

REGLA CLAVE: no crear LOT duplicados, LOT ficticios ni LOT representativos fuera del procedimiento.
01

Pasos comunes

Completa estos pasos antes de decidir cómo recuperar el LOT.

1

Escanea el producto físico

Identifica el producto y comprueba qué LOT no se puede localizar.

2

Registra el caso en Excel

Anota los productos reales y el resultado de la revisión.

3

Consulta en GMS → Multi Lote

Busca toda la lista y verifica el estado de cada LOT.

4

Después de escanear el código, ¿qué estado ves?

Distingue entre ausencia total de información y un LOT existente eliminado del proceso.

IDENTIFICA EL CASO
CASO 1 · SIN REGISTRO

No existe información del LOT

Qué significa

Escaneas el código, pero no aparece información del LOT en GMS/MES.

Qué hacer

Confirma el tipo de flujo y crea un LOT individual solo para cada producto físico existente. Después genera y escanea el QR correcto.

CASO 2 · ELIMINADO EN PROCESO

La información existe, pero fue eliminado del proceso

Qué significa

El código sí muestra la información del LOT, pero el registro del LOT fue eliminado en el proceso.

Qué hacer

Restaura el LOT existente según el procedimiento de planta (“품위”) y vuelve a verificarlo en GMS/MES. No crees un LOT nuevo.

02

Decisión principal

Usa solo la condición que confirmaste en GMS y en el proceso físico.

RUTA A · INFORMACIÓN EXISTENTE

La información del LOT existe

A1. LOT existente, eliminado del proceso

Restaura el LOT existente mediante el procedimiento de planta indicado como “품위”. Después, vuelve a consultar y confirma el estado. No generes otro LOT.

A2. LOT válido y proceso correcto

No crees otro LOT. Registra la verificación en Excel y cierra el caso cuando todos los controles estén completos.

A3. El proceso no coincide

Envía el producto al proceso correcto. Verifica otra vez que la ubicación física y el historial MES coincidan.

RUTA B · SIN REGISTRO

No existe información del LOT

B1. No hay información del LOT

Confirma el tipo de flujo (externo o Main/Sub). Después, sigue el procedimiento de creación correspondiente.

B2. Crea solo LOT reales

Crea un LOT individual únicamente para cada producto físico existente. Genera el QR correspondiente y escanéalo en el proceso aplicable.

B3. No completes cantidades con LOT ficticios

Si faltan productos del conjunto, crea LOT solo para los productos que realmente existen. No generes un LOT representativo para completar la cantidad.

03

Reglas especiales

Comprueba estas reglas cuando el caso sea de flujo externo, Main/Sub o LOT representativo.

Flujo externo

Si el LOT externo no aparece:

  • Crear solo LOT individuales para productos reales.
  • Generar el QR y escanearlo en el proceso que corresponda.
  • No crear LOT representativo ni LOT ficticios.

Flujo Main/Sub

Recuerda qué hace y qué no hace Lote Main Line:

  • Lote Main Line crea LOT individuales, no el LOT representativo.
  • Si el conjunto está incompleto, crea LOT solo para los productos reales.
  • Gestiona el LOT representativo por separado y empareja Main/Sub cuando ambos estén disponibles.

Caso especial · Router ya cortó

Si Router ya cortó el producto y el LOT individual no se puede escanear, restaura el LOT representativo según la regla documentada. Después, verifica el estado en GMS/MES.

Si el LOT individual sí se puede escanear, no restaures el representativo automáticamente: verifica Main/Sub, QR y proceso.

04

Validación final

Cierra el caso solo después de verificar estos puntos.

✓ Estado del LOT confirmado en GMS/MES
✓ Proceso físico e historial MES coinciden
✓ Resultado registrado en Excel
Si el estado no está claro, no inventes un paso: deja el caso pendiente y confirma con el responsable del proceso.
