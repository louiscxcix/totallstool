GUÍA DE RECUPERACIÓN CASO PRINCIPAL: SIN LOT / SIN LOTE REPRESENTATIVO

SIN LOTE Recovery Guide

Esta guía ayuda a entender por qué aparece un caso SIN LOTE y cómo recuperar cada unidad paso a paso. La regla de trabajo es la definida para este proceso: primero escanear y consultar en GMS Multi Lote; después recuperar el LOT existente o generar únicamente los LOT que corresponden a los productos reales.

REGLA PRINCIPAL

La existencia del LOT, el estado de eliminación, el proceso registrado y la cantidad física son verificaciones distintas. No generes un LOT nuevo hasta consultar GMS Multi Lote. No generes un LOT representativo si no están presentes todas las unidades requeridas por el conjunto de ese modelo.

01 · ANÁLISIS DE CAUSA

¿Por qué puede ocurrir un caso SIN LOTE?

El material proporcionado describe los estados y los errores que deben corregirse, pero no incluye los registros de un incidente concreto. Por eso distinguimos los hechos descritos de las causas posibles que deben comprobarse.

A

El LOT nunca se generó

Hecho observable: GMS Multi Lote no devuelve un LOT para el código consultado. Causas posibles: se omitió el paso de creación, el registro no se completó, o el LOT externo no existe/no se encuentra. La consulta por sí sola no confirma cuál de estas causas ocurrió.

Qué revisar: código usado, resultado de consulta y si se trata de flujo Main/Sub o externo.

B

El LOT fue creado y después quedó eliminado

Hecho observable: hay evidencia de creación, pero el estado actual es eliminado. El motivo de la eliminación no aparece en el material disponible; debe revisarse en el registro correspondiente y no suponerse.

Qué revisar: estado del LOT y registro disponible de eliminación. Acción indicada por el procedimiento: restaurar mediante la función/procedimiento llamado “품위” en la nota del usuario.

C

El proceso real y el proceso MES no coinciden

Hecho observable: el LOT existe, pero la ubicación/proceso físico no coincide con el historial. Causas posibles por investigar: no se registró el escaneo de una operación, se registró en un proceso equivocado o el producto se movió sin actualizar su estado. Son hipótesis, no causas confirmadas.

Qué revisar: producto físico, LOT consultado, proceso mostrado en MES y proceso al que realmente corresponde.

D

No existe o es incorrecta la relación Main/Sub

Cuando el caso usa LOT representativo y LOT individuales, ambos deben quedar emparejados en Main/Sub. Si esa relación falta o conecta LOT incorrectos, la estructura del LOT no refleja el conjunto real.

Qué revisar: LOT representativo, LOT individuales y las relaciones registradas entre ellos.

E

Se intenta crear un LOT representativo con un conjunto incompleto

Riesgo confirmado por la regla de trabajo: si el modelo necesita 6 LOT individuales pero solo existen 4 productos, crear un representativo de 6 puede dejar 2 unidades/LOT ficticios. Este error se evita comparando el conjunto requerido con la cantidad física antes de generar.

F

El QR se generó, pero no se verificó en el proceso correcto

El QR, el registro LOT y el escaneo del proceso son pasos relacionados, pero no son lo mismo. Un QR creado no demuestra por sí solo que el LOT esté correctamente registrado ni que la unidad haya sido escaneada.

Qué revisar: el contenido del QR, el producto al que pertenece y el resultado del escaneo en el proceso correspondiente.

Conclusión del análisis

El problema general es una ruptura entre tres cosas: el producto que existe físicamente, el LOT/QR que lo identifica y el proceso que GMS/MES registra. Para determinar la causa raíz de un incidente concreto, hay que conservar el código escaneado, el resultado de Multi Lote, el estado del LOT, el proceso real y la acción aplicada. No se debe marcar una causa como confirmada solo porque el síntoma coincide.

Regla de cantidad para LOT representativo

Ejemplo: el modelo necesita 6 LOT individuales y solo hay 4 productos. No crees un LOT representativo de 6. Crea LOT individuales para los 4 productos reales. La regla es la misma aunque el conjunto requerido sea de 4, 5 o 6: debe estar físicamente completo para crear el representativo.

03 · PASO A PASO

Procedimiento detallado para principiantes

1

Escanear y registrar el material en Excel

Reúne los productos SIN LOTE. Escanea cada código disponible y deja una fila por cada unidad/código escaneado. Conserva el modelo y la cantidad real. Revisa que no haya duplicados ni productos omitidos. En esta etapa solo se prepara la lista; todavía no se crea ningún LOT.

2

Consultar toda la lista en GMS Multi Lote

Copia la columna de códigos preparada y pégala en el campo de consulta de Multi Lote según el formato que admita la pantalla. Ejecuta la consulta y devuelve cada resultado a su fila de Excel. Separa claramente los resultados con LOT de los que no devuelven LOT.

3

Separar los resultados en dos grupos

  • Grupo A: LOT sí existe. Revisa si está eliminado y si su proceso corresponde a la ubicación real.
  • Grupo B: LOT no creado/no encontrado. Confirma el modelo, el conjunto que corresponde y la cantidad física antes de generar.
4

Si el LOT existe, restaurar o corregir el proceso

  • Si el LOT está eliminado: utiliza el procedimiento indicado como “품위” para restaurarlo. Después vuelve a consultarlo.
  • Si no está eliminado pero el proceso es diferente: envíalo al proceso que corresponde. Confirma que el estado final y la ubicación real coincidan.
  • Si LOT y proceso están correctos: no generes otro LOT. Registra que se verificó.
5

Si el LOT no existe, identificar el tipo de flujo

Confirma el modelo y el número de unidades físicas. Determina si el caso requiere relacionar LOT representativo e individuales en Main/Sub, o si corresponde al flujo externo. No elijas el flujo solo por el nombre del producto; utiliza la clasificación real del caso.

6

Validar la cantidad antes de crear un LOT representativo

Comprueba cuántos LOT individuales exige el conjunto del modelo y cuenta los productos reales. Si el estándar requiere 6 y solo hay 4, crea LOT individuales solo para esos 4. No crees un representativo ni completes las dos unidades faltantes con LOT ficticios. Si es externo y no se encuentra el LOT externo, crea solo los LOT individuales reales.

7

Crear LOT usando la ruta correcta

  • Para un caso Main/Sub con conjunto completo: entra a Lote Main Line, selecciona el modelo y genera el LOT representativo y los LOT individuales que corresponden.
  • Después entra a Main/Sub y empareja el LOT representativo con sus LOT individuales.
  • Para un conjunto incompleto, o un caso externo sin LOT externo: crea solo un LOT individual por cada producto real. No crees LOT representativo.
8

Generar el QR y escanearlo en el proceso correspondiente

Genera el QR del LOT creado/restaurado según la regla aplicable. Escanea el QR en el proceso correspondiente. Comprueba que el código leído coincide con el LOT y el producto reales. Crear una imagen QR no reemplaza el registro LOT ni el escaneo del proceso.

9

Cerrar el caso en Excel

Registra el resultado final de cada código: restaurado, enviado al proceso correcto, LOT individual creado, LOT representativo y Main/Sub completados, o pendiente de aclaración. No marques como terminado un registro que aún no se comprobó.

04 · CONTROL FINAL

Lista de verificación

Marca cada punto solo después de comprobarlo en el producto o en el sistema.

Caso separado: el LOT representativo ya existe

La instrucción proporcionada para este caso es: comprobar si Router ya cortó el producto; si está cortado pero el LOT individual no se puede escanear, se debe restaurar el LOT representativo. El flujo completo de este caso se añadirá por separado, tal como se indicó; no se mezcla con el procedimiento de representante ausente.

Límite de este análisis

Las causas indicadas como posibles requieren evidencia real de GMS/MES o del proceso para confirmarse. Los pasos y las reglas de cantidad siguen las instrucciones de trabajo proporcionadas. No se inventan nombres de botones que no se hayan mostrado en la pantalla real.
